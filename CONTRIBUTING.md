# Contributing to deg-nexustk

## Build and test

```console
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test
cargo run -q -- check examples/synthetic/model.dg
```

## Generated fixtures

Everything under `examples/synthetic/` (except `model.lock.json`, which is a
seal artifact) and `tests/gen_data/mod.rs` is generated by
`tools/gen_fixtures.py` — an independent Python implementation of the
documented 7.52 algorithms. After changing the generator or the codec,
regenerate and commit the result:

```console
python3 tools/gen_fixtures.py
```

The generator is deterministic and idempotent: two runs must leave the tree
byte-identical (`git status` clean the second time).

## README excerpts are machine-checked

The pasted outputs in the "See it work — synthetic" section of `README.md`
(and the matching synthetic walkthrough in `docs/demo.md`) are re-run against
the built binary and diffed byte-for-byte:

```console
python3 tools/verify_readme.py
```

If a change alters any of that output, re-capture it and update the README in
the same commit — the verifier must pass. The "See it work — against the real
artifacts" section is operator-local (marked `<!-- verify-skip -->`) and is
never verified automatically or in CI; keep its pasted numbers attributed to
the machine and day they came from.

## Ground rules

- Nothing here is copied from the emulator project: all code and fixtures are
  derived from the documented 7.52 protocol behavior under fair use. No
  operator-local file, capture body, key table, credential, or client binary
  is committed; the real-artifact lanes are env-gated and never run in CI.
- External, capture-derived analysis stays capped at Observational; only
  kernel-replayed facts reach Deterministic.
